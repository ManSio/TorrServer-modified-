## Built-in TorrServer auth (since 2026-11-06 21:14)

TorrServer runs with `--httpauth` and reads `/var/lib/torrserver/accs.db`
(plain JSON, mode 600, owner `torrserver`). Auth is enforced by TorrServer itself on
**8090**, and nginx on 80/443 just proxies — so there is one credential store, not two.

```
http://torr.mansio.freemyip.com:8090/stat       -> 401 without credentials, 200 with
https://torr.mansio.freemyip.com/stat           -> 401 without credentials, 200 with
```

Consequence: Prisma/TorrServe, which do not send Basic Auth, will no longer connect to
8090. Apps need to support login/password or go through a no-auth endpoint/VPN.

## Auth

TorrServer built-in Basic Auth (`server/web/auth/auth.go`) protects all requests on
8090; nginx forwards the header, so 80/443 are covered too. Script:
`/usr/local/sbin/torrserver-auth` (repo copy: `scripts/torrserver-auth.sh`) writes
`accs.db` and restarts TorrServer.

```
sudo torrserver-auth                 # asks for login and password (hidden, confirmed)
sudo torrserver-auth user pass       # set explicitly
```

URL for players: `https://user:password@torr.mansio.freemyip.com/`.
