## System tuning

`/etc/sysctl.d/99-torrserver.conf`: `vm.swappiness=10`, `fs.file-max=200000`,
16 MiB TCP buffers. UFW: 51413/tcp and 51413/udp allowed; 8090 stays loopback-only.

## Auth

nginx Basic Auth (`/etc/nginx/.htpasswd-torrserver`) protects the whole vhost,
including WebSocket upgrades and streaming. Script: `/usr/local/sbin/torrserver-auth`
(repo copy: `scripts/torrserver-auth.sh`).

```
sudo torrserver-auth                 # asks for login and password (hidden, confirmed)
sudo torrserver-auth user pass       # set explicitly
```

URL for players: `https://user:password@torr.mansio.freemyip.com/`.
